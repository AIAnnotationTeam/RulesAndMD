
**课题介绍**

# 1.项目概述
- 项目名称： RepReady (Web)  
- 平台： Web  
- 目标： 将现有的 iOS RepReady 应用训练体验同步在 Web 进行实现。复用后端 API/核心功能。Web 端的范围包括新的前端页面以及企业管理后台的附加功能。
- 用户角色：
  - 企业管理员 (Admin)： 使用管理员后台管理团队仪表板、RAG 知识库、公司设置和成员邀请。
  - 企业成员/销售代表 (User)： 使用训练 Web 应用进行练习、查看进度、回顾历史记录和管理个人设置。
- 设计： UI 按照Figma进行设计。


---------------


# 2.企业管理后台

## 2.1 仪表板
仪表板包括两个标签页：

标签页 A：团队
- 显示团队层级的指标：
  - 总练习时间
  - 平均得分
  - 平均语音/听力比
  - 平均开放式问题数量
- 团队成员列表（表格）列：
  - 代表
  - 平均得分
  - 总练习数量
  - 总练习时间
  - 准备度得分
- 每个成员行是可点击的，点击后打开成员详情页：
  - “练习与总结”
  - 点击每个代表 查看他们的全部练习历史：
    - 查看每个练习会话的详细内容
    - 访问 反馈/分析、上下文、转录 和 KPI/指标
      
标签页 B：总结
- 显示整个团队的 “总结”
  
## 2.2 RAG (知识库管理)
- 管理员可以在后台管理公司知识库：
  - 支持 拖拽 创建/组织（例如，安排文件/卡片/文件夹）
  - 支持 添加 和 删除
  - 保存的知识库内容将作为 开始练习 的训练来源
    
## 2.3 设置
- 企业账户设置
- 公司网站 URL（可选）
  - 如果管理员提供了公司网站 URL，则会触发一个后台处理过程：
    - 网站抓取
    - AI 数据清理
    - 将处理后的信息持久化到后台
- 团队管理（成员邀请）
  - 管理员输入员工的电子邮件地址
  - 系统发送 邀请链接
  - 邮箱将作为默认成员标识符（创建/添加成员）
- 服务条款与隐私政策
  - 提供阅读/查看的入口

# 3. 用户 Web 应用（销售代表）

## 3.1 注册/登录
- 基于电子邮件的注册/登录  
- 认证方式：电子邮件 + 密码
- 密码重置 功能已包括。
  
## 3.2 首页模块：“开始练习”
两种开始方式：
1. 直接开始练习
  - 使用企业管理员上传/维护的知识库（RAG）作为训练来源
2. 使用自定义输入开始练习
  - 用户可以输入/配置自定义信息来生成一个练习场景并开始训练
    
## 3.3 模块 2：“我的进度”
- 显示用户的个人训练仪表板
  
## 3.4 模块 3：“练习历史”
- 查看个人的练习记录列表
- 支持查看单个练习会话的详细内容：
  - 录音
  - KPI
  - 标签：
    - 反馈（当前页面）
    - 上下文（AI 生成的背景、场景）
    - 转录（音频到文本的对话转录）
      
## 3.5 模块 4：“设置”
- 个人资料编辑
- 用户提供的 URL：
  - 无需抓取，仅用于 数据存储
- 服务条款与隐私政策的阅读/查看入口
  

---

# 4. RAG 知识库

- 支持的文件格式： PDF、DOC、TXT、EXCEL
- 权限： 知识库内容无需权限；仅限管理员后台访问。用户 Web 应用与管理员后台是分开的，仅供最终用户使用。
  

---

## 5. 开始练习流程

1. 开始练习： 用户可以点击一个按钮，基于上传的知识库内容开始练习。
2. 自定义练习： 用户可以输入文本，将其注入到提示中生成练习场景并开始训练。
3. 基于语音的练习： 用户可以通过仅语音互动进行练习。Web 版本支持 麦克风录音 和 音频播放。
