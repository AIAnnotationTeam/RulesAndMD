# 项目中所有的技术选型和设计 必须是工业级的主流方案，禁止使用临时方案
比如：数据本地存储要使用数据库，禁止使用一个json文件在本地存储。


# 在实现了一个功能开发后，必须有对应的单元测试，禁止只写代码而不管代码质量。

# 在项目中的一个方法里禁止出现多个if else。
如果有多个if else的场景，则使用**继承（利用多态）**或者**策略**这类开发模式来解决。
## **继承（利用多态）**的使用举例：
···
 如果场景为：这个if else的场景里处理的数据同时涉及到属性和方法
 1.定义一个基类（里面定义方法）。
 2.子类重写基类的方法。
 3.创建一个功能处理器，然后使用组合模式，在这个功能处理器中，根据不同的if else条件，使用不同子类进行处理。
 4.在需要处理这类问题的地方拿出这个功能处理器进行处理。
 ···

## **策略**的使用举例：
···
如果场景为：这个if else的场景里处理的数据只涉及到方法，
1.定义一个协议（里面定义方法）。
2.在需要包含这个功能的类中实现这个协议的方法。
3.创建一个功能处理器，然后使用组合模式，在这个功能处理器中，根据不同的if else条件，使用不同的包含这个功能的类进行处理。
4.在需要处理这类问题的地方拿出这个功能处理器进行处理。
···


# 在项目中要用设计模式来组织对象关系，禁止简单的功能堆积


# 如项目中同时使用到了后台数据库 和 本地数据库时，必须保证两个数据库中同一个表的字段定义完全一样，中间业务代码解析，传递，使用都要完全保持一致。保证从后台数据库来的数据在本地存储，使用，完全是拉通的。
