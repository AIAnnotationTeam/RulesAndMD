
# 【全局】技术栈约束 (Swift 5.0 / UIKit)

以下规则适用于**所有层级** (L0-L3) 的代码，定义了本项目的具体技术栈、API 限制和主流开发范式。

## 1. Swift 5.0 规范
* **禁止 (高优先级):** **绝对禁止**使用 `async / await`, `@MainActor`, `Combine` 或 `SwiftUI` 相关的 API。
* **强制 (异步):** 所有异步操作**必须**使用**闭包回调 (completion handlers)** 模式。
* **强制 (错误处理):** 异步回调**必须**使用 `Result<Success, Error>` 类型来封装成功或失败。

## 2. UI 规范
* **框架:** 项目**必须**使用 **UIKit**。
* **布局 (高优先级):** UI 布局**必须**使用 `SnapKit` 库进行程序化布局。
* **禁止 (布局):** 禁止使用 `NSLayoutConstraint.activate` 或手写 `frame` 布局（除非在 `layoutSubviews` 中进行微调）。

## 3. 内存管理 (高优先级)
* **强制:** 在所有捕获 `self` 的闭包（Closures）中，**必须**使用 `[weak self]` 捕获列表，以防止循环引用。

## 4. 线程与 UI 更新
* **强制:** 任何更新 UIKit 组件（如 `UILabel`, `UITableView`）的代码，都**必须**通过 `DispatchQueue.main.async` 显式派发到主线程。

## 5. 数据模型 (Data Models)
* **JSON 解析:** 所有的数据模型 (Models) **必须** 遵循 `Codable` (或 `Decodable`/`Encodable`) 协议进行 JSON 解析。
* **禁止:** 禁止使用 SwiftyJSON 或手动字典解析等旧方法（除非是维护旧代码）。

## 6. 网络请求 (Networking)
* **库优选:** 网络请求**优先**使用 `Alamofire` 库（如果已在 `Podfile` 中引入）。
* **基础实现:** 如果未使用 `Alamofire`，则**必须**使用 `URLSession` (例如 `URLSession.shared.dataTask(with: ...)`）并结合第 1 节中定义的闭包回调和 `Result` 类型进行。

## 7. 数据绑定 (Handler -> VC)
* **通信方式:** L1 的 `Handler` 与 `ViewController` 之间的通信**必须**使用**闭包回调** (例如: `handler.onDataUpdated = { [weak self] data in ... }`) 或**KVO (Key-Value Observing)** 来实现数据绑定和事件通知。

## 8. 图像加载 (Image Loading)
* **库优选:** 所有网络图片的加载和缓存**必须**使用 `Kingfisher` 库（如果已在 `Podfile` 中引入）。
* **禁止:** 禁止在 `cellForRowAt` 中直接使用 `Data(contentsOf:)` 或 `URLSession` 手动下载图片，以避免阻塞主线程和重复下载。
