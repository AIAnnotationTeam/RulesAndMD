| 业务需求 | 优先评估 |
| --- | --- |

## 16. 实施前的选型检查

| 要回答的问题 | 判断方式 |
| --- | --- |
| 最终需要什么输出 | 先明确文本、图片、视频、音频、向量或实时事件，再选模型 |
| 输入是否真的支持 | 核对文件格式、图片数量、音频编码、视频输入和大小；简介与能力表有差异时以可验证接口为准 |
| 一次任务还是持续会话 | 文件生成 / 转写按任务组织，实时识别 / 合成 / 对话 / 同传按协议管理连接 |
| 地域与账号是否匹配 | 确认目标地域的模型权限、API Key、Endpoint、业务空间和计费方案 |
| 型号是否精确 | 完整保存 ID、供应商前缀、大小写和版本；快照、稳定别名、Preview 与 Realtime 分别管理 |
| 语言质量是否达标 | 用目标方向、口音、噪声、术语和重叠发言样本测试，不只看支持语言列表 |
| 并发与限流是否够用 | 按型号 RPM、TPM、连接与任务额度设计排队、退避和容量保护 |
| 费用按什么计算 | 分清各模态 Token、字符、图片张数、音视频时长、分辨率及参考输入 |
| 免费额度是否适用 | 检查地域、有效期、型号和账号条件，不将体验额度当成长期生产预算 |
| 任务能否恢复 | 保存任务 ID 和状态，超时后先查任务，不盲目重复创建付费生成任务 |
| 结果链接是否过期 | 按 API 核对有效期并转存，不将临时 URL 当长期业务存储 |
| API 是否兼容 | OpenAI 兼容、DashScope、异步任务和 Realtime 是不同路径，不只改 Base URL 就认定通用 |
| 素材和身份是否获授权 | 对人脸、声音、证件和私有视频设计授权、隔离、保留期限与删除 |
| 输出怎样验收 | 对 OCR、海报文字、商品一致性、转写、翻译及音视频分别设置业务检查 |
| 费用能否控制 | 密钥保存在服务端，设置用户额度、任务 / 并发上限和费用监控；提醒不等于费用封顶 |
| 是否完成最小接入验证 | 用目标地域实际调用，验证请求、结果、失败、限流和恢复后再固定进架构 |
