# 同言 Tongyan · UI / UX 设计

面向跨语言远程团队的桌面会议产品。设计方向为「安静、清晰、人人能参与」：浅色会前工作台、深色会中舞台、薄荷绿状态提示，优先保证字幕和个人语言频道的可见性。

## 推荐体验路径

| 顺序 | 操作 | 观察重点 |
| --- | --- | --- |
| 起点 | 首页 → 发起即时会议 | 创建与加入明确分开，访客无需注册 |
| 准备 | 填写昵称、选择语言、勾选处理告知 | 设备默认关闭；未勾选不能开始 |
| 沟通 | 进入会议 → 语言频道 | 目标语言与界面语言分开；原声为默认方式 |
| 协作 | 参与者 → 允许加入 → 共享屏幕 → 聊天 | 待审批不占在线席位；共享时字幕持续可见 |
| 设置 | 字幕字号、叠加位置、原文显示 | 布局只影响本人 |
| 恢复 | 设置 → 演示翻译故障 → 重试翻译 | 翻译故障与音视频状态分开 |
| 结束 | 离开会议 → 结束所有人的会议 → 二次确认 | 清除当前内容，不出现会后记录入口 |

## 原型边界

这是用于评审的前端设计原型。音视频、验证码、预约、翻译、成员审批、权限变更和聊天送达均为本地模拟，不连接真实后端或模型，不采集设备。测试音由本地浏览器合成。刷新页面重置示例内容，不写入浏览器持久存储。

临时品牌名「同言 Tongyan」用于建立一致的视觉语言，正式产品名确认后可统一替换。

## 语言设置说明

选择“将其他人的发言翻译成：中文普通话”，即可把其他人的日语、韩语和英语发言统一转换为中文字幕；需要中文声音时选择“字幕＋译音”。中文发言保留原声，系统自动识别来源语言，无需多选。
