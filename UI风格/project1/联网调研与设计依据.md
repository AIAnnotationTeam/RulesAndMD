# 联网调研与设计依据

本次直接访问公开官方页面，提取页面可读内容后用于设计判断。这里只说明可核查的布局和交互做法，不把厂商宣传中的准确率、延迟或规模当成本产品承诺，也不宣称存在唯一的“最新主流审美”。

| 调研项 | 信息 |
| --- | --- |
| 访问日期 | 2026-10-30，北京时间 |
| 调研方式 | 直接联网获取官方页面；检查正文而非仅查看页面标题 |
| 优先采用 | 官方设计系统、官方使用流程、可访问性规范 |
| 风格结论 | 清晰分区、固定控制栏、上下文侧栏、个人偏好、渐进披露、可见状态 |

| 来源 | 访问结果 | 实际核实内容 | 对本方案的影响 |
| --- | --- | --- | --- |
| [Microsoft Fluent 2 · Layout](https://fluent2.microsoft.design/layout) | 已读取完整可读正文 | 间距 ramp、网格、内容区域、断点；通过 reflow、resize、show/hide 保持阅读层级 | 采用一致间距、明确内容区与右侧辅助面板；窗口变窄时调整密度 |
| [Wordly · How Translation Software Works](https://www.wordly.ai/translation-software) | 已读取完整可读正文 | 参会者通过链接加入、选择个人语言、按需阅读字幕或收听音频；发言者使用偏好语言 | 语言频道属于个人；字幕＋原声与字幕＋译音并列选择；把语言入口放在会中可触达位置 |
| [W3C · Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) | 已联网读取页面 | 普通文本与背景对比度门槛、大字号文本例外、文字与背景的辨识要求 | 译文强调对比；状态配合文字；生产实现逐组件检查，而非笼统宣称通过认证 |
| [Material 3 · Understanding layout](https://m3.material.io/foundations/layout/understanding-layout/overview) | 官方页可达，返回 JavaScript 加载提示 | 本环境无法从静态响应读取具体布局正文 | 只列探索记录，不把未读正文当作本次结论依据 |
| [Google Meet · Translated captions](https://support.google.com/meet/answer/10964115?hl=en) | 本次请求未在限时内取得有效正文 | 未新增核实具体功能或最新界面 | 仅保留产品文档已有参考；本次设计结论不依赖该页面 |

Wordly 的移动端、语言规模、会后转录、术语表等能力超出本产品首发范围，不带入本方案。Fluent 布局为原则参考，不代表本产品使用或复制其商标、截图及完整组件样式。

| 参考原则 | 本产品实现决策 | 需求约束 |
| --- | --- | --- |
| 个人语言接收 | 会中固定“我的语言频道”面板 | 目标语言仅影响本人，不切换界面语言 |
| 渐进披露 | 常用语言与收听方式直接展示，字号/音量/源语言纠正在设置内 | 避免会中塞满选项 |
| 内容主次分区 | 视频和共享为舞台，字幕独立固定下方，管理放侧栏 | 共享时也必须读到字幕 |
| 稳定控制位置 | 底栏保持麦克风、摄像头、共享、字幕、语言、聊天、成员、设置、离开顺序 | 减少会中寻找入口 |
| 多通道状态表达 | 发言边框＋文本，媒体连接与翻译故障独立展示 | 不能把翻译故障误报为整场断线 |
| 可恢复失败 | 保留原声和原文，提供重试与明确原因 | 模型故障不能直接结束会议 |
