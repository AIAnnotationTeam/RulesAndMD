## 交付限制

| 项目 | 后续生产验收 |
| --- | --- |
| 真正实时翻译 | 按产品文档验证语音、文字、译音、源语言纠正、字幕归属和切换边界 |
| 设备与弱网 | 真实浏览器授权、设备拔插、自动播放、RTC 连通性、断线恢复 |
| 服务端权限 | 容量竞争、审批时限、锁房、主持权移交、移出与重复接管 |
| 账号 | 邮箱验证码、所有者恢复、收回主持权、删除账号 |
| 预约 | UTC 存储、动态日期范围、夏令时、允许开始窗口与过期裁决 |
| 生命周期 | 真实服务端计时、临近上限提醒、超时结束和全部掉线宽限 |
| 内容安全 | 后端长度限制、消息幂等、安全外链、服务端日志抽检与缓冲清理 |
| 无障碍 | 稳定版 Chrome / Edge、屏幕阅读器、放大、高对比和完整键盘路径 |
| 当前示例数据 | 固定时钟与示例预约日期用于复现设计，不代表真实可开始状态 |

原型不宣称已验证真实会议、模型性能、翻译质量或数据服务行为。
