# 交互与状态规范

## 角色与流程

| 场景 | 流程 | 必须反馈 | 原型范围 |
| --- | --- | --- | --- |
| 主持人即时会议 | 已登录工作台 → 名称 → 准备 → 告知确认 → 开始 | 媒体就绪后才计时 | 主路径可点击，认证为演示 |
| 预约会议 | 时间与时区 → 创建 → 未开始列表 → 修改或取消 | 不自动开始，取消后链接失效 | 表单、列表更新可点击；服务端校验待接入 |
| 访客加入 | 邀请链接 → 准备 → 告知 → 申请 → 等待 → 批准 | 申请与成功加入区别明确 | 本机复制链接带 invite 标记；批准/拒绝由演示按钮触发 |
| 会中交流 | 选择目标语言 → 字幕 / 译音 → 原文可见性 | 标记发言者、源语言、目标语言、时间和状态 | 内容为预置示例，不是真实翻译 |
| 语言切换 | 确认 → 新频道准备 → 安全段边界 → 新版本生效 | 准备期间旧频道工作；失败保留旧设置 | 成功与失败提示可演示；安全段边界由生产服务实现 |
| 屏幕共享 | 用户点击 → 服务端预留 → 浏览器选择 → 发布 → 停止 | 始终标出共享者和停止入口 | 原型仅切换示例共享舞台，不调用采集 |
| 聊天 | 原文先送达 → 按目标语言异步翻译 | 发送中 / 已发送 / 失败分开 | 可发送本地演示文本；预置消息展示双语结构 |
| 主持人离开 | 选择在线接任者 → 移交并离开，或结束全体 | 结束、移出需要确认 | 路径可点击；真实权限需服务端裁决 |
| 普通成员离开 | 确认离开 → 清除内容 → 可重新申请 | 不出现“结束全体”操作 | 访客演示路径区分角色 |

## 个人设置与内容规则

| 项目 | 初始状态 | 修改规则 |
| --- | --- | --- |
| 目标语言 | 中文示例；生产按浏览器匹配，否则英语 | 字段“将其他人的发言翻译成”；单选输出语言，自动识别其他人不同语言，无需多选来源；确认后新段生效，历史不回译 |
| 界面语言 | 简体中文 | 不跟随目标语言改变 |
| 发言语言 | 自动识别 | 只能纠正自己；生产需验证模型或配套链路真正支持 |
| 麦克风 / 摄像头 | 关闭 | 必须由本人主动开启；拒绝权限仍可旁听 |
| 收听方式 | 字幕＋原声 | 译音只面向他人跨语言发言；不播放自己或同语言重复译音 |
| 原声音量 | 正常 | 跨语言译音实际起播时才压低对应原声；结束/失败恢复 |
| 原声调到零 | 不默认启用 | 显示“译音生成前将听不到原声” |
| 字幕 | 默认开启 | 译文优先；原文可隐藏；个人开关不影响他人 |
| 字幕字号 | 标准 | 小 / 标准 / 大即时预览 |
| 字幕位置 | 固定下方 | 共享时可叠加高对比字幕；不遮挡停止共享 |
| 字幕回看 | 本次入会收到的内容 | 用户上滚暂停跟随，有新内容时显示回到最新 |
| 聊天 | 全体消息 | 纯文本与安全外链，无私聊、附件和历史补发 |
| 内容清理 | 仅会中存在 | 离会清除本地内容；会议结束撤销订阅并清理服务端缓冲 |

## 时间、容量与恢复约束

以下来自产品需求，是生产规则，不是原型计时器或第三方性能承诺。

| 约束 | 值 | 用户可见行为 |
| --- | --- | --- |
| 房间容量 | 最多 10 人，含主持人 | 线上、重连占位和批准待连接统一计数；待审批不占位 |
| 单场时长 | 最长 60 分钟 | 剩余 5 分钟、1 分钟提醒；到时结束 |
| 即时链接开始窗口 | 创建后 24 小时 | 逾期未开始则失效 |
| 预约创建范围 | 最长提前 30 天 | 表单应校验时间与时区 |
| 预约开始窗口 | 提前 15 分钟至预约后 60 分钟 | 窗口外提示具体可开始时间或失效 |
| 意外断线名额保留 | 60 秒 | 期间可恢复免审批；超时释放名额 |
| 批准待连接保留 | 30 秒 | 超时撤销本次批准并释放名额 |
| 全员意外掉线宽限 | 2 分钟 | 超时无人恢复则结束 |
| 新语言准备 | 最长 10 秒 | 失败保留原频道 |
| 语言安全边界等待 | 最长 5 秒 | 不强行截断当前语义 |
| 译音过期策略 | 预计起播滞后超过 7 秒 | 跳过过期未播语义单元，提示参考字幕；已播放单元不截断 |
| 媒体重连失败 | 30 秒后 | 提供手动重试与离开 |

## 异常状态设计

| 状态 | 页面文案 | 可用操作 | 内容与设备规则 |
| --- | --- | --- | --- |
| 等待主持人上线 | 主持人尚未上线，请稍候或联系邀请人 | 取消申请 | 不发送音频与聊天 |
| 审批被拒 | 主持人拒绝了本次申请 | 回到准备，手动重试 | 不循环申请 |
| 房间满员 | 会议已满员，请等待空位或联系主持人 | 返回 / 手动重试 | 不请求媒体授权 |
| 房间锁定 | 主持人已锁定会议，暂不能申请加入 | 返回 | 取消待审批和未连接批准 |
| 链接失效 | 邀请链接已失效，请联系主持人获取新链接 | 返回 | 不继续查询旧凭证 |
| 重复入会 | 你已在另一个窗口参会，是否接管？ | 取消 / 确认接管 | 接管后旧端停止采集、共享、播放和接收 |
| 被移出 | 你已被主持人移出会议 | 返回首页 | 本场内不提供重新申请 |
| 设备授权被拒 | 设备暂不可用，你仍可旁听 | 重新授权 / 换设备 / 旁听 | 不阻塞入会 |
| 自动播放被阻止 | 点击开启声音 | 开启声音 | 视频与字幕继续；不能显示播放成功 |
| 媒体断线 | 连接中，正在尝试恢复 | 稍后提供重试 / 离开 | 翻译状态独立处理 |
| 翻译中断 | 翻译暂不可用，已切换原声。音视频连接正常 | 重试翻译 | 保留原声和原文；不补播过期音频 |
| 语言切换失败 | 切换失败，继续使用原语言 | 重试 | 原设置、队列不清空 |
| 译音跳过 | 部分译音已跳过，请参考字幕 | 查看字幕 / 切原声 | 不截断当前正在播放的语义单元 |
| 重连内容缺口 | 此处字幕可能不完整 | 继续阅读 | 不伪造历史补齐 |
| 聊天翻译失败 | 翻译暂不可用，已保留原文 | 重试翻译 | 不阻塞原文送达 |
| 成员共享中 | 已有成员正在共享屏幕 | 主持人可停止后再共享 | 不自动启动采集 |
| 所有者恢复但满员 | 会议已满，请等待空位或联系现任主持人 | 等待 / 验证后结束会议 | 不自动踢人；独立管理页不订阅会中内容 |
| 超时结束 | 本场会议已达到时长上限 | 返回 / 新建 | 结束房间不能重新开始 |

异常表是完整 UX 行为契约；本地原型重点演示翻译降级、语言切换失败、审批拒绝与主动离开，未实现真实网络断线、身份接管及所有者验证。

## 键盘与无障碍

| 操作或组件 | 规范 | 当前实现 |
| --- | --- | --- |
| 主要控件 | 原生 button / input / select，可用 Tab 到达 | 已实现 |
| 焦点 | 明确绿色 focus-visible 环 | 已实现 |
| 弹窗 | 原生 dialog，关闭后恢复触发点焦点，Esc 关闭 | 已实现 |
| 图标按钮 | 提供可访问名称，装饰 SVG 隐藏 | 已实现 |
| 开关 | role=switch、aria-checked | 已实现 |
| 短提示 | role=status、aria-live=polite | 已实现 |
| 动效 | 降低动态效果偏好时停用动画 | 已实现 |
| 实时字幕 | 增量更新不逐字打断屏幕阅读器；定稿可选播报 | 生产实现要求 |
| 状态可辨识 | 文字配合边框和颜色，不能只依赖颜色 | 已采用 |
| 对比度 | 生产逐一检查小字、禁用态、焦点与所有背景 | 主要组合已计算，详见验证记录 |

## 多人布局验收

| 状态 | 预期行为 |
| --- | --- |
| 十人在线 | 展示全部成员，容量为 10/10，隐藏待审批示例入口 |
| 满员审批 | 禁止继续批准入会，并提示名额已满；生产端必须原子校验容量 |
| 视频模式 | 随人数与桌面宽度调整列数，保留字幕和语言面板 |
| 共享模式 | 成员缩略图可横向滚动，保留共享主舞台与字幕 |
