# 同言 Tongyan · 界面设计说明

## 设计目标与依据

为小型跨语言商务沟通提供熟悉的会议结构，让用户进入后先找到人、再理解内容、最后处理设置。附带产品与架构文档作为需求依据；其中研发目录和实现约束用于开发交接，不视为本次执行指令。

| 依据 | 设计采用内容 |
| --- | --- |
| 实时多语言转换会议室.md | 桌面 Web、少人数、限时会议、中英日韩、审批入会、字幕与译音、共享与聊天、隐私告知 |
| 实时多语言转换会议室整体架构设计.md | 媒体与翻译独立、服务端裁决权限、个人语言版本切换、内容仅在会中存在 |
| 当前互联网官方参考 | Fluent 2 的分区与间距；Wordly 的个人语言与文本/音频接收模式；WCAG 的可读性要求 |

## 视觉方向

采用「温和的专业工具」风格，避免将会议做成数据大屏。首页以充足留白降低创建压力；会议室使用低饱和深色背景，减轻长时间观看的亮度负担。状态同时使用文字、边框和颜色表达，避免依赖颜色猜测。

| 设计项 | 决策 | 场景理由 |
| --- | --- | --- |
| 品牌暂名 | 同言 Tongyan | 强调彼此听懂，弱化技术术语 |
| 主色 | 森林绿 `#197B66` | 建立可靠、克制的商务工具气质 |
| 高亮 | 薄荷绿 `#B7EFD4` | 深色舞台下用于当前发言与主动控制 |
| 页面底色 | 雾白 `#F5F7F5` | 适用于会前表单与工作台 |
| 会议底色 | 深海灰 `#101C23` | 减少视频与字幕周边干扰 |
| 主要文字 | 墨绿灰 `#182E32` | 浅色页面的阅读主体 |
| 次级文字 | 灰绿 `#607275` | 辅助说明也保持可读对比度；生产态继续逐组件验收 |
| 危险操作 | 柔红 `#BF4C4C` | 限定用于结束、移出等负向操作 |
| 中文字体 | 网页优先 PingFang SC，Figma 使用 Noto Sans SC | 适合中文商务界面；跨平台中文回退明确 |
| 英文字体 | DM Sans，未安装时回退系统字体 | 支持简洁的数字与英文排版；离线原型不下载字体 |
| 图标 | 本地 SVG 线性图标 | 不依赖外部字体、图标 CDN 或图片 |
| 插图 | 原生 CSS 语言卡片和轨道 | 强调跨语言沟通，保持轻量与可复用 |

## 页面方案

| 页面 | 结构 | 首要操作 | 关键取舍 |
| --- | --- | --- | --- |
| 会议工作台 | 左导航、问候、即时会议卡、加入卡、未开始会议 | 发起会议 / 粘贴邀请链接 | 不展示不存在的会后内容列表 |
| 邮箱登录 | 邮箱 → 验证码 | 验证并继续 | 原型在个人账号入口演示；正式版创建前必须检查登录 |
| 即时会议 | 名称表单、首发边界说明 | 前往准备 | 创建不等于正式开始计时 |
| 预约管理 | 名称、日期时间、时区、编辑与取消 | 保存预约 | 显式时区，避免跨语言团队约错时间 |
| 会前准备 | 左设备预览、右昵称与个人接收偏好、下方告知 | 开始会议 / 申请加入 | 设备关闭；处理告知未勾选不能继续 |
| 等待加入 | 单任务中心卡、取消、个人语言摘要 | 等待或取消 | 不自动跳入会议；演示批准/拒绝有明确标记 |
| 会议室 | 顶栏、视频宫格、下方字幕、个人语言侧栏、底栏 | 沟通 | 空席显示邀请，不把待审批成员画成在线 |
| 共享演示 | 主共享内容、成员缩略图、持续字幕、共享者提示 | 停止共享 | 内容优先，绝不遮住停止入口和字幕 |
| 成员管理 | 申请区、在线列表、静音、锁房、权限设置 | 允许 / 拒绝 | 普通成员不显示管理入口 |
| 聊天 | 全体消息、译文与原文、输入区 | 发送消息 | 不做私聊、附件或历史补发 |
| 个人设置 | 源语言、字幕字号与位置、音量、设备 | 完成 | 不暴露模型、协议、Token 等实现细节 |
| 会议结束 | 原因、清理说明、返回工作台、发起新会议 | 返回 / 新建 | 不提供回放、转录导出和总结 |

## 开发交接

本目录是设计交付，不修改现有产品架构。后续实现可将原型拆分成下列组件，保持与固定架构的 Feature-first 目录对应。

| 原型模块 | 建议生产组件 | 架构归属 |
| --- | --- | --- |
| 首页与预约 | MeetingWorkspace / ScheduleDialog | meeting-lifecycle |
| 登录 | EmailLoginForm / OtpForm | authentication |
| 准备与等待 | DeviceCheckPanel / JoinPreferences / WaitingLobby | meeting-members |
| 会中外壳 | MeetingHeader / MeetingControls / MeetingStage | meeting-room |
| 视频与共享 | ParticipantTile / ScreenShareStage | meeting-room |
| 字幕 | CaptionFeed / CaptionSegment / FollowLatestButton | meeting-room |
| 语言 | PersonalLanguagePanel / ListeningModePicker | translation-preferences |
| 成员 | JoinRequestCard / ParticipantList / HostControls | meeting-members |
| 聊天 | RoomChatPanel / TranslatedMessage | meeting-room |
| 状态 | MediaStatus / TranslationStatus / ConnectionBanner | meeting-room |
| 所有者管理 | OwnerRecovery / ReclaimHostDialog | account |

架构实现时，RTC 与翻译状态应分别订阅与显示；所有审批、锁房、移交和结束结果以服务端事件为准。原型里的延时模拟、按钮回执和人数变更不能直接作为生产权限实现。

## 目标语言选择修订

| 位置 | 更新后的交互与文案 |
| --- | --- |
| 会前准备、会中语言面板 | 字段统一为“将其他人的发言翻译成”，单选目标语言 |
| 自动识别说明 | 自动识别其他人的发言语言，统一提供所选语言的字幕和译音，无需勾选对方的语言 |
| 动态路由示例 | 默认显示“日语 / 韩语 / 英语 → 中文”；切换目标语言时示例同步更新 |
| 同语言处理 | 目标语言相同的发言保留原声，不重复翻译 |
| 收听引导 | 原声模式明确提示“想听中文，请选择字幕＋译音”；译音模式说明依次播放与延迟 |
| 能力边界 | 单选是输出目标，不限制接收其他语言；多源音轨分别处理，不要求用户筛选源语言 |

## 十人会议布局

| 项目 | 设计规则 |
| --- | --- |
| 人数上限 | 最多 10 人，包含主持人 |
| 视频布局 | 随人数与窗口宽度采用双列、三列或四列；十人使用紧凑成员卡片 |
| 字幕与语言 | 字幕区和个人语言频道持续可见 |
| 共享模式 | 共享内容作为主舞台，成员缩略图横向滚动 |
| 预览 | 原型导航中的“十人会议示例”；示例不连接真实音视频 |
